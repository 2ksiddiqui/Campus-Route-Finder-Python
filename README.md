# Campus Route Finder — Python

An interactive campus navigation desktop application developed using **Python, CustomTkinter, Tkinter, and Dijkstra's shortest-path algorithm**.

## Overview

Campus Route Finder helps users identify efficient walking routes between campus buildings using graph-based pathfinding.

This project is the Python implementation of my Campus Route Finder application, which I also developed in Java. Building the application in two programming languages demonstrates my experience with object-oriented programming, algorithm implementation, and graphical user interface development.

## Features

- **Shortest-Path Calculation:** Uses Dijkstra's algorithm to determine efficient routes between campus buildings.
- **Interactive Campus Map:** Displays buildings, connecting pathways, and selected routes.
- **Modern User Interface:** Built using CustomTkinter and Tkinter.
- **Building Selection:** Allows users to choose starting locations and destinations.
- **Route Visualization:** Highlights calculated routes on the campus map.
- **Search Functionality:** Helps users locate buildings.
- **Swap Locations:** Quickly reverses starting and destination points.
- **Route History:** Keeps track of previously calculated routes.
- **Route Comparison:** Allows users to compare different routes.
- **Export Functionality:** Supports exporting route information.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Install the required library:

   `python -m pip install customtkinter`

5. Run the application:

   `python CampusRouteFinderPython.py`
